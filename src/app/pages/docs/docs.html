Search syntax

Elemental Reach uses a SICK-compatible query language. Combine free text with field filters. Terms separated by spaces are ANDed; use | for OR and ! for NOT.

Fields

set, type, name, cost, speed, range, target, elements (alias e), artist, description, kind, tags, spirit, aspect

Element letters

Use a letter (or pack several) instead of full element names. Animal is N so A means Air.

    @for (row of elementLetters; track row.letter) {
  • {{ row.letter }} {{ row.element }}
    • }

Examples: ps = Plant + Sun, e:fn = Fire + Animal.

Element set operators

Compare a card’s element set to a letter pack:

  • e=asm — exactly Air, Sun, and Moon
  • e>a — has Air and at least one more element
  • e>=ps — has at least Plant and Sun
  • e<=as — only Air and/or Sun (no other elements)
  • e<as — proper subset of Air/Sun (e.g. only Air)

Examples

    @for (ex of examples; track ex.query) {
  • {{ ex.query }} {{ ex.note }}
    • }

Tips

  • Comparisons on numbers: cost:<3, range:>=2, cost:=1
  • Quotes for multi-word phrases: "add 1 presence"
  • Bare words like major, minor, unique, innate, or aspect match via free text / tags
  • Element letter packs only match when every character is an alias (so plant / sun still work as normal text)
  • Press s anywhere (outside inputs) to focus the search box
