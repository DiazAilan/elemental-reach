Search syntax

Elemental Reach uses a SICK-compatible query language. Combine free text with field filters. Terms separated by spaces are ANDed; use | for OR and ! for NOT.

Fields

set, type, name, cost, speed, range, target, elements, artist, description

Examples

    @for (ex of examples; track ex.query) {
  • {{ ex.query }} {{ ex.note }}
    • }

Tips

  • Comparisons on numbers: cost:<3, range:>=2, cost:=1
  • Quotes for multi-word phrases: "add 1 presence"
  • Bare words like major, minor, or unique match the type field via free text
  • Press s anywhere (outside inputs) to focus the search box
